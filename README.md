# JavaPaint

Простой растровый редактор на Java Swing. Проект не использует сторонние библиотеки и системы сборки. Достаточно JDK 17 или новее.

## Запуск

**В VS Code:** откройте папку проекта и запустите `src/App.java` кнопкой Run.

**Через терминал Windows** (из корневой папки проекта):

```powershell
javac -encoding UTF-8 -d out src\*.java
java -cp out App
```

**Через терминал Linux/macOS:**

```bash
javac -encoding UTF-8 -d out src/*.java
java -cp out App
```

BAT-файл пока не добавлен: он будет подготовлен на завершающем этапе.

## Что умеет текущая версия

- Рисовать карандашом, кистью, ластиком и распылителем.
- Заливать области и выбирать цвет пипеткой.
- Добавлять текст.
- Рисовать линии, прямоугольники, скруглённые прямоугольники, эллипсы, треугольники и ромбы.
- Выбирать фигуру из компактного выпадающего списка.
- Настраивать цвет, толщину линий и заливку фигур.
- Включать сетку и видеть прозрачность на шахматном фоне.
- Отменять и повторять до 50 действий (Ctrl+Z и Ctrl+Y).
- Открывать и сохранять PNG, JPEG, BMP и GIF.

## Как устроен код

Код разделён на небольшие классы. Каждый класс отвечает за свою задачу.

### `App.java` — запуск программы

Создаёт главное окно, устанавливает системный стиль, добавляет холст и панель инструментов. Здесь же находятся горячие клавиши и иконка приложения.

### `Toolbar.java` — панель инструментов

Создаёт кнопки, выпадающий список фигур, выбор цвета, толщины и команды открытия/сохранения. Методы разделены по назначению: создание панели, выбор цвета и работа с файлами.

### `Canvas.java` — холст и действия мышью

Обрабатывает нажатие, перемещение и отпускание мыши. Отображает изображение, сетку, шахматный фон и предварительный контур фигуры.

### `DrawingDocument.java` — изображение и история

Хранит пиксели изображения, открывает и сохраняет файлы, выполняет заливку, отмену и повтор действий. В нём нет кода интерфейса.

### `ShapeDrawer.java` — геометрические фигуры

Отвечает только за отрисовку фигур. Каждая фигура вынесена в отдельный понятный метод.

## Принцип организации

- `App` собирает приложение.
- `Toolbar` сообщает холсту, какой инструмент выбран.
- `Canvas` обрабатывает действия пользователя.
- `DrawingDocument` хранит изображение и историю.
- `ShapeDrawer` рисует геометрические фигуры.

Так проще найти нужное место в коде и добавлять новые возможности, не превращая один файл в огромный набор несвязанных методов.

## Что ещё не реализовано

Слои, полноценное выделение, трансформации, собственный формат проекта, расширенные фигуры и градиенты. Эти функции будем добавлять отдельными этапами после проверки текущей версии.
